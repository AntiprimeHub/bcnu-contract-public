# ARTICLE 16 – Employee Evaluation — Gains & Losses
Source: `changes/article-16-employee-evaluation.md` · Baseline: `current/sections/article-16-employee-evaluation.md`

**Tally:** ✅ 3 gains · ❌ 0 losses · ➖ 0 neutral · ⚠️ 2 watch-outs

## ✅ Gains
- **16.03(A) Automatic record removal** — Disciplinary records are now removed/destroyed **automatically** after 18 months. The old precondition "**Upon request of the employee**" is struck, so nurses no longer have to ask for stale discipline to be purged. *(Art. 16.03(A), PDF p.57 / doc p.55)*
- **16.03(A) Suspensions purged** — New sentence: suspension records **shall be removed and destroyed** 18 months after the suspension expires (old text only said they'd "remain on file for 18 months" — silent on destruction). Clear destruction obligation added. *(Art. 16.03(A), PDF p.57 / doc p.55)*
- **16.03(B) Letters of expectation purged faster** — Removal is now **automatic** ("Upon request" struck) and the clock drops from **18 months → 12 months**. *(Art. 16.03(B), PDF p.57 / doc p.55)*

## ⚠️ Watch-outs
- **⚠️ SILENT EDIT — "by the Employer" inserted (unmarked).** In 16.03(A) the booklet quietly added the words **"by the Employer"** to the removal/destruction clause ("...shall be removed **by the Employer** from the employee's file and destroyed..."). Only "shall" is underlined as a tracked change; **"by the Employer" is plain/unmarked**, so it does not show as an insertion. The current agreement reads only "...shall be removed from the employee's file and destroyed..." User-confirmed this is a genuine unmarked change in the source booklet. Likely benign (assigns who must act, supporting automatic removal), but it was slipped in untracked — verify and surface to voters. *(In 16.03(B) the same words "by the Employer" were also added, but there they ARE underlined/tracked as an insertion — the unmarked, silent edit is only in 16.03(A).)* *(Art. 16.03(A)/(B), PDF p.57 / doc p.55)*
- **New "16.X Employer Investigations" MOA — read both ways.** *Pro-nurse reading (✅):* adds process protections — Employer must **notify the Union** when a nurse is put on administrative leave pending a possible-discipline investigation, state the nature of the issue, work "in a timely fashion," and **explain any delay beyond 21 days**; results flow through the existing 9.06 / 15.04 protections. *Employer-right reading (⚠️):* it also formally **acknowledges the Employer's power to place nurses on administrative leave and investigate**, and the 21-day timeline is soft — delays are excused for "contingencies beyond the Employer's control," and the Employer may withhold detail it believes "could compromise the investigation." On balance it codifies notice/timeliness duties that did not previously exist, but it is not a hard deadline. Judge in light of Appendix references. *(Art. 16.X(A)-(D), PDF p.58 / doc p.56)*
